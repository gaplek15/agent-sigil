How it works

  1. You hold an Agent ID (.ai name) — a non-transferable ERC-721 on BNB Smart Chain.
  2. You connect your wallet and press Mint. The contract checks on-chain that your address holds at least one Agent ID (balanceOf > 0).
  3. If the check passes, you receive Sigil #N — an ERC-721 whose name, description and image live entirely on-chain (JSON + SVG, base64). Nothing depends on a server staying alive.
  4. The badge can never be transferred or approved to anyone. It is yours as long as you keep it; burn it any time to renounce it.

What this is not

Agent Sigil is a proof-of-identity badge, not an investment. It pays no yield, promises no return, and gives no financial benefit. There is no token sale, no fee, and no admin key: the contract has no owner and no privileged functions at all — nobody, including its deployer, can mint for you, change the art, or take a badge away.
